# 原始视频

新实验统一从此处读取视频；不覆盖、编辑或重新编码原片。

- `michelson-original.mp4`：来自大四上版本的 `真实场景(全).mp4`，与大三下版本的 `真实场景.mp4` 内容相同。
- `michelson-bilibili.mp4`：来自大四上版本的 `真实场景(b站).mp4`。原网页链接与作者尚未提供，不将其归为用户自录材料。

视频元数据、来源归档路径和 SHA-256 在上一层的 `videos.json` 中。上述文件为独立副本，归档和原片均保留；没有以快捷方式替代视频。

人工标注另存于 `data/annotations/`。所有实验使用实际时间戳，不能仅凭文件中的名义帧率推算经过时间。
