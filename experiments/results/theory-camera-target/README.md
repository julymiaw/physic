# 受控理论图样

按早期 `experiments/simulation.py` 同类的共同相位余弦模型重新绘制：图样为红色，绿色与蓝色通道置零；固定圆形亮区内，红通道强度为 `.55+.33*cos(28*(r/.9)^2+2*pi*C(t))`，圆盘外为低亮度背景。没有人为加入噪声、形变或照明漂移。不是复原大学时期某张旧图，也不是新算法的真实场景成绩。

优先用浏览器打开 `index.html`：点“标定图样”让条纹单向移动，在手机上圈选整个亮圆盘并标定。成功后暂停网页；在手机上开始测量，再点网页“推进10.25圈”。图样自行停住，稍等确认后手机应显示10个完整净周期。多出的四分之一周期用于避开精确整数边界的滞回歧义，不应解释为10圈位移。

也可播放 `theory-camera-test.mp4`：0–6秒圈选，6–12秒单向标定，12–18秒图样静止并在手机上开始测量，18–28.25秒推进10.25周期，余下时间保持图样并停止手机测量。计数目标10，不包含标定期间的运动。

`direct-pipeline.json` 记录同一公式的256像素未压缩图样，经过正式RGBA面积积分与生产WASM的结果：整数10，连续估计约10.2401，完整。它没有覆盖MP4压缩、显示器输出、手机曝光/回调和实时调度；下一步就是手机拍这个图样后比较结果，保留STREAM日志。如果理想图样能通过、原片仍拒绝，可优先研究拍摄后信号结构；如果理想图样仍拒绝，则继续检查相机映射、信号提取和设备运行过程。两种结果都不能单独证明拍屏是唯一原因。

生成：`.venv/bin/python tools/make_theory_target.py`；直接管线检查：`node tests/theory_camera_target.cjs`。
