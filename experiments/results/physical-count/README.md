# 光屏跟踪与物理相位计数：本轮结果

**按用户认可的34秒局部歧义规则通过自录开发验证。** 88个确定事件全部一对一匹配，漏计0、多计0、方向错误0；算法另输出34秒的一对可选减一、加一，局部结束净值不变。不能将这90个输出事件都称为已独立裁定的物理真值，也不代表其他拍摄场景已经通过。

**参考依据。** 原片连续时空切片全段检查一次，84个正向事件附近连续画面逐一检查第二次，并复查停顿、反转和片尾。原画面显示46–47秒后一次往返未让暗环到达中心，删除原来的成对事件；29秒高分辨率原片显示两次真正回穿，保留两对−/+。34.378、34.753秒小亮点的精确物理解释仍不确定；用户明确接受两种解释，只要求局部最终净值相同。此例外只在评估参考中，算法不读取标注、不含这些时间的特殊规则。

参考v3和两轮输出保留。v4补充第二次29秒回穿和用户认可的34秒判定规则，附SHA-256；其余参考为AI视觉复核的开发依据，未经整段独立人工复核。依据见 `review/turn29-hi.jpg`、`review/turn.jpg`、`review/question-34.jpg`，全部来自真实原片。

**为什么原中心跑到(28,23)。** 复现旧标定得到该位置的时间对称相关误差0.356437，低于(30,32)的0.367046，旧目标函数因此确实选择错误位置；它衡量相对点时间信号是否相似，不能唯一约束周期条纹的几何中心。新版本用已对齐标定条纹的空间梯度方向，鲁棒拟合二次相位结构，得到干涉中心(29.569,31.532)，与光屏轮廓中心分开。标定和计数均直接从带余量96像素图采样到同一64像素坐标，无紧框截断。

**零点与确认。** 共5个3×3采样块，4路中心／辅助信号相位观测。自动暗心锚点为236、250、262、272帧；以这些共同时间为各路设置零点，周期间最大偏差0.06792圈。第一轮把同一暗心周期的两个碎片重复当锚点，第二轮按标定相位进度合并。之后冻结中心、采样位置、归一化和零点；多路证据结合最多4帧缓冲确认跨越，保留真实短时回穿，不再按返回时间取消成对事件。发生时间累计与实时已确认显示分列保存。

原轮廓跟踪参数未改；抽成共享C++实现后，1206帧变换和质量值与历史回放一致，只有坐标偏移换算的18个浮点末位差异，最大低于1e-12。截断验证覆盖已确认输出；计数决策最多读取当前事件后4帧。计时包含跟踪、采样、相位确认及片尾处理，排除解码、预处理、初始化、文件读写；计时与非计时结果逐字节相同。没有运行合成测试、B站视频或WASM。

## 复现与查看

在项目根目录运行 `research/replay_physical.sh`，会编译Native C++、完整回放、核对固定v4参考并做截断检查，默认不重复计时；新输出写入 `experiments/runs/self-recorded/`，不覆盖本目录的冻结证据。输入为已有真实派生缓存 `experiments/results/real-track/padded-screen.frc`，原片保持不变。

- `reference-v4.json` / `.sha256`：确定事件、局部歧义及依据。
- `frames.csv`：逐帧发生时间轴；`.events.csv`：发生与确认时刻；`.online.csv`：接收时刻已确认显示。
- `final/event-comparison.csv`、`final/checkpoints.csv`、`final/accuracy.json`：逐事件、检查点、完整验收结果。
- `causality.json`、`tracker-parity.json`、`timing.json`：截断、跟踪复用及单次计时证据。
- `physical-count-explained.mp4`：56秒可视化，显示原片、跟踪后的坐标、采样点、4路相位和实时确认计数，并显式标记34秒歧义。

计数核心为 `research/real_pair.cpp`；轮廓跟踪为 `research/screen_tracker.h`。计时所用源文件另存为 `timed-source.cpp`；当前实现只增加了坐标偏移输入选项，默认自录输出与计时版本逐字节相同。这是当前自录开发结果；大角度倾斜、其他机位与手机性能仍未验证。
